# Why four of the six iterations replay to nothing, and what that cost:
#
# Their logs are ALREADY truncated on disk. spawnRunner capped stdout at the first 200KB
# and dropped the rest, and a claude stream carries its usage, its cost and the agent's
# final message in the LAST event. The correlation is exact — the two logs under the cap
# have a result event, the four at or over it have none:
#   1.log    193,243 bytes  intact  result event: present
#   2.log    122,467 bytes  intact  result event: present
#   3.log    203,768 bytes  capped  result event: GONE
#   4.log    200,374 bytes  capped  result event: GONE
#   5.log    200,590 bytes  capped  result event: GONE
#   6.log    200,258 bytes  capped  result event: GONE
#
# So the four numbers above are a FLOOR on what the run cost: the true total is higher by
# whatever iterations 3-6 spent, which those logs can no longer say. spawnRunner now keeps
# a 50KB rolling tail inside the same 200KB budget, so a future run records all six.
